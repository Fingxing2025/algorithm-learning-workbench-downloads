## 第一次使用

1. Windows 运行 EXE 并按安装向导操作；macOS 打开 DMG，把应用拖入“应用程序”。
2. 启动软件，新建一个空白工作区，选择本地文件夹保存资料。
3. 在模板库粘贴或导入自己的源码，直接保存；创建题目卡片并关联实际使用的模板。
4. 需要时配置自己的 AI 服务。使用前检查发送预览，生成内容确认后才保存或执行。
5. 赛前选择已有内容编成比赛准备包，预览并导出离线 HTML / PDF；重要操作前导出工作区备份。

本地操作无需配置 AI。业务数据保存在工作区文件夹；AI 配置与密钥不包含在工作区备份里。远程 AI 功能按发送预览把选中内容交给用户配置的服务，服务可能另行收费。
